How it works

One key per app. That's the whole idea.

⌥T
Terminal
1

Bind a shortcut to an app

Pick any app from the menu bar and give it a key combo you'll remember.

⌥T
2

Press it to focus the app

From anywhere, on any screen. No Dock, no ⌘-Tab roulette.

3

Press again to cycle its windows

Three terminals open? Keep tapping to step through them, in order.

Features

Small app. Sharp edges sanded off.

⌘

Per-app shortcuts and cycling

One shortcut per app. Press to focus, press again to cycle through its windows.

Four layouts

Wide split, tall split, fullscreen or floating. Windows snap neatly into place.

Splits that stay put

Jump to another app and back. Your split is exactly where you left it.

Multi-monitor aware

Works across every connected screen. Shortcuts find the app wherever it lives.

Lives quietly in the menu bar

No Dock icon, no windows of its own. Lightweight and out of your way.

Free and open source

MIT-licensed. Read the code, file an issue, send a pull request.

Layouts

Four ways to arrange a screen.

Wide split

Stacked top and bottom. Great for editor over terminal.

Tall split

Side by side. Code on the left, preview on the right.

Fullscreen

One window, every pixel. No Space switching.

Floating

Windows sit where you drop them.

Install

A few commands, and you're set.

Install SnapDesk with Homebrew$brew tap pedroknup/tap
$brew trust pedroknup/tap
$brew install --cask snapdesk

macOS 14 Sonoma or later

Runs natively on Apple silicon and Intel Macs on Sonoma and newer.

Needs Accessibility permission

Allow it in System Settings › Privacy & Security › Accessibility so SnapDesk can move and resize windows.

Prefer a download? Grab the latest build from GitHub Releases.
Signed with a Developer ID and notarized by Apple.
